** WFS

#+begin_src latex
\newcommand*{\wfsX}{4}
\newcommand*{\wfsWaveSpace}{.89}
\newcommand*{\wfsWidth}{8}
\newcommand*{\wfsNumWaves}{5}
\newcommand*{\wfsNumSecondary}{16}
\newcommand*{\wfsNumMCU}{8}

\tikzset{
  cross/.pic = {
    \draw[rotate = 45] (-#1,0) -- (#1,0);
    \draw[rotate = 45] (0,-#1) -- (0, #1);
  },
  wfsModule/.pic = {
    \node [module] {dWFS};
  },
  wavefronts/.pic={
    \foreach \pos/\rad in {0/.18, 1/.615, 2/1.03, 3/1.42, 4/1.78, 5/2.07, 6/2.295, 7/2.42} {
      \draw [black!25] (-\wfsX+.25+.5*\pos, 2) circle (\rad);
    }
  },
  speaker/.pic={
    \path [draw=black, fill=white] (-.11, 0) rectangle (.11, .06);
    \path [draw=black, fill=white] (-.11, .06) -- (-.25, .2) -- (.25, .2) -- (.11, .06);
  },
  wfs/.pic={
    % Virtual sound field
    \draw (-\wfsX, -.5) rectangle (\wfsX, 2);
    
    \begin{scope}
      \clip (-\wfsX, -.5) rectangle (\wfsX, 2);

      % Virtual sound source
      \node [circle, draw=audioColour, fill=audioColour!50, thick]
      (primary) at (0, 0) {};

      % Virtual wavefronts
      \foreach \i [
        evaluate=\i as \rad using \i*\wfsWaveSpace
      ] in {1,...,\wfsNumWaves} {
        \draw [thick, dashed, audioColour] (-\rad, 0)
        arc [radius=\rad, start angle=180, end angle=0];
      }

      % Labels
      \node [
        black!50, fill=white, align=center,
        font={\footnotesize\itshape}
      ] at (-3.15, .1) {Virtual\\soundfield};
      \node [
        below right=-1mm and -1mm of primary,
        font={\footnotesize\itshape}
      ] {Virtual sound source};

      \foreach \i [
        evaluate=\i as \secondary using
        -\wfsX+.25+(\i-1)*(2*\wfsX/\wfsNumSecondary)
      ] in {1,...,\wfsNumSecondary} {
        \node (\secondary) at (\secondary, 2) {};
      }

      % Virtual source co-ordinates and ctrl line
      \draw [ctrl] node [above right=.1mm, font=\ultratiny]
            {\((x, y)\)} (primary) -- (0, 2);
    \end{scope}

    % Infrastructure
    \begin{scope}[yshift=2cm]
      \node (server) [device, inner xsep=7.5mm] at (0, .75) {Server};
      \node (authority) [authority, above=4mm of server]
            {Time\\authority};
      \node (switch) [device, inner xsep=7.5mm, above=4mm of authority]
            {Switch};

      % USB arrow
      \draw [usb] ([xshift=-5mm] authority.south) --
      ([xshift=-5mm] server.north)

      % PTP arrows
      \draw [ptp] (authority.north) -- (switch.south);
      \draw [-{Triangle}] ([xshift=5mm] authority.south) --
      ([xshift=5mm] server.north);

      % Audio arrow
      \draw [audio] ([xshift=-11mm] server.north) --
      ([xshift=-11mm] switch.south);

      % Control arrow
      \draw [ctrlArrow] ([xshift=11mm] server.north) --
      ([xshift=11mm] switch.south);

      % Modules
      \foreach \i [
        evaluate=\i as \xpos using -\wfsX+.5+(\i-1)*(2*\wfsX/\wfsNumMCU)
      ] in {1,...,\wfsNumMCU} {
        \pic at (\xpos, 4.6) {wfsModule};
        
        \draw [audio] (\xpos-.2, 4.0) -- (\xpos-.2, 4.375);
        \draw [ctrlArrow] (\xpos, 4.0) -- (\xpos, 4.375);
        
        \ifnum\i=1
          \draw [-{Triangle}] (switch.north) +(0, .325) --
          (\xpos-.2, 4.0) (\xpos+.2, 4.0) -| (\xpos+.2, 4.375);
        \else
          \ifnum\i=\wfsNumMCU
            \draw [ptp] (switch.north) -- +(0, .325) -| (\xpos+.2, 4.375);
          \else
            \draw [-{Triangle}] (\xpos+.2, 4.0) -- (\xpos+.2, 4.375);
          \fi
        \fi
      }

      % Secondary sources
      \foreach \i [
        evaluate=\i as \secondary using
        -\wfsX+.25+(\i-1)*(2*\wfsX/\wfsNumSecondary)
      ] in {1,...,\wfsNumSecondary} {
        \pic at (\secondary, 0) {cross=2pt};
        
        \ifnum\i=1
          \draw [ctrl] (\secondary,0) -- +(0, .2) -|
          ([yshift=-3mm] server.south);
        \else
          \ifnum\i=\wfsNumSecondary
            \draw [ctrlArrow] (\secondary,0) --
            +(0, .2) -| (server.south);
          \else
            \draw [ctrl] (\secondary,0) -- +(0, .2);
          \fi
        \fi

        \pic at (\secondary, 4.845) {speaker};
      }

      \draw [ctrl] (0, 0) -- (0, .2);
    \end{scope}

    % Synthesised soundfield
    \begin{scope}[yshift=5.055cm]
      \clip (-\wfsX, 2) rectangle (\wfsX, 4.6);

      \foreach \i [evaluate=\i as \rad using \i*\wfsWaveSpace] in {1,...,\wfsNumWaves} {
        \draw [thick, audioColour] (-\rad, 0) arc [radius=\rad, start angle=180, end angle=0];
      }

      \pic {wavefronts};
      \pic [xscale=-1] {wavefronts};

      \node [black!50, align=center, font={\ultratiny\itshape}] at (-3.15, 4) {Synthesised\\soundfield};
    \end{scope}
  }
}
#+end_src

*** Motivation                                                      :B_block:
:PROPERTIES:
:BEAMER_env: block

#+latex: \justifying

Audio over ethernet is the de facto standard in multichannel audio
transmission, and yet existing networked audio systems are either
proprietary and expensive (e.g., Dante) or unsuited to timing-critical
applications such as spatial audio (e.g., JackTrip, AOO). We propose
/Ananas/, a networked audio system consisting of:

- A protocol suite for audio and control data transmission, device
  discovery, and synchronisation.
- Digital audio workstation-based interfaces for spatial audio control.
- Microcontroller firmware for distributed, parallelised spatial audio
  algorithms.

Ananas seeks to lower the barrier to entry for the sound field
synthesis techniques of wave field synthesis (WFS) and higher order
ambisonics (HOA). Typically, systems for WFS and HOA are centralised,
reliant on costly highly-multichannel audio interfaces and their
accessibility is thus limited. Representing a distributed alternative,
Ananas renders access to such systems more attainable.

Distributing things in this manner requires that our group of signal
processors is *synchronised*, however, otherwise the resulting
soundfield will be destroyed.  A 1\nbsp{}ms asynchronicity between two
distributed audio devices would result in a *propagation discrepancy* of
over 30\nbsp{}cm.

*** Asynchronicity                                                  :B_block:
:PROPERTIES:
:BEAMER_env: block
:END:

#+latex: \justifying

We can configure a network of audio-capable devices (Teensy 4.1
microcontroller development boards) to run at a given target sampling
rate, but if we had a way of measuring /true/ time − and thus true
frequency − we would find that they're actually running *slightly
faster* or *slightly slower* than instructed.

Each device has its own *distinct internal time reference* − a crystal
oscillator (XO) − and each one of those time references behaves
slightly differently. XOs are rated to a given tolerance − typically
reported in /parts per million/ (ppm) − an amount by which they may be
expected to deviate from their nominal frequency.

*** Time Exchange

**** Left
:PROPERTIES:

:BEAMER_opt: [T]

#+latex: \justifying

IEEE 1588 *Precision Time Protocol* (PTP) is a nanosecond-order
time-exchange mechanism. Clock authority and subscriber(s) exchange
per-second timestamped packets until the subscriber has enough
information to determine its *drift* and *offset* relative to the
authority. These values are typically fed to a proportional integral
controller, and the result used as a /nanoseconds-per-second/
adjustment value to be applied to a dedicated PTP timer.

Consumer-grade networking equipment does not tend to support PTP, but
relatively inexpensive exceptions do exist. What's more, our chosen
microcontroller platform supports it too\nbsp[cite:@schleusnerSubMicrosecond2024].

**** Right
:PROPERTIES:
:BEAMER_col: 0.38
:BEAMER_opt: [T]
:END:

\begin{gather*}
\text{Drift} = 1 - \frac{t'_{2}-t_{2}}{t'_{1}-t_{1}}\\[10pt]
\text{Delay} = \frac{(t_{4} - t_{1}) - (t_{3} - t_{2}) }{2}\\[10pt]
\text{Offset} = t_{2} - t_{1} - \text{Delay}
\end{gather*}

#+latex: \justifying

Conditioning the media clock alone is not enough. To guarantee that
samples will be *presented simultaneously*, we wait until a sub-100 ns
PTP lock is achieved (takes about ten seconds) to start clock
subscriber audio subsystems. This entails starting presentation time
on a given PTP second, so it's easiest when working with a nominal
sampling rate that's a multiple of the buffer size!
